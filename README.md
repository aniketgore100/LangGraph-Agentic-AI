# 🧠 Agentic Orchestration Playground

A personal learning sandbox where I'm learning **agentic orchestration** with **Python** and **[LangGraph](https://langchain-ai.github.io/langgraph/)** — with the goal of building **agentic systems and environments**.

This repo is where I experiment, practice, and grow my understanding of how autonomous agents are designed, orchestrated, and connected together.

---

## 🚀 Getting started

```bash
# activate the virtual environment
source venv/bin/activate

# install dependencies
pip install langgraph pydantic

# launch the notebook
jupyter notebook Agent.ipynb
```
